AMBIANCE ULTRAWIDE
========

Shows games pixel-sharp on ultrawide monitors and fills the empty space
with ambient light made from the game's own colors. Free and open source (MIT).

HOW TO USE
1. Run AmbianceUltrawide.exe. (No installation needed.)
   If Windows shows "unknown publisher": More info -> Run anyway.
2. Run your game in windowed or borderless mode.
3. In Ambiance Ultrawide, pick the game from the list and press Start.
   Or press Ctrl+Alt+A while in game.

SHORTCUTS
  Ctrl+Alt+A   Turn ambient light on / off
  Ctrl+Alt+Z   Toggle scaling

Closing the window keeps Ambiance Ultrawide running in the system tray.
To quit, right-click the tray icon and choose Exit.

Ambiance Ultrawide collects no data and makes no network connections.
Requires Windows 10 (2004+) or Windows 11, 64-bit.
